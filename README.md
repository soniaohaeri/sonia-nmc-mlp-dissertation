# NMC–MLP Dissertation Code

Python implementation supporting the dissertation:

**Evaluating Optimiser-Trained MLP Surrogates against Nested Monte Carlo
Simulation for Interest-Rate Risk Estimation**

The repository contains code for:

- Hull–White simulation and SONIA cap valuation
- Nested Monte Carlo valuation
- Reduced inner-path sensitivity experiments
- MLP training with Adam, Adagrad and Shampoo
- VaR and Expected Shortfall estimation
- Bootstrap confidence intervals
- Predictive and convergence diagnostics
- Cloudie optimiser ranking

The Bloomberg GBP SONIA OIS input file is not included.

Python version: 3.13.5
